# Elise Philips — 3D-galerij (www.deschira.com)

Leder · Interieur · Architectuur. Een fotorealistische 3D-rotonde gebouwd met three.js.

- `index.html` — de hele website (three.js via CDN)
- `assets/` — vaste beelden (tassen, landschap, materialen)
- `content.json` — startinhoud; zodra de beheerder opslaat komt de inhoud uit Supabase
- Inloggen, inhoud, foto's/video's, klantaccounts en aanvragen: Supabase-project `elise-philips-website`

De vorige website staat in de branch `oude-site`.
